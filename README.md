# Chat
* una vista para poder definir un usuario     
    * se puede definir el usuario en cualquiera punto de aplicacion
* una vista para crear salas(nombre, sala publica o privada, capacidad)
    * la sala creada tiene la posibilidad de volver a cambiar sus parametros
    * el dueño puede eliminar a alguien de la sala
    * el dueño puede eliminar la sala y expulsa a todos 
* otra vista que estan listadas esas salas
    * las salas deben tener una capacidad requerida
    * las salas deben tener una manera de idfentificar si son publicas o privadas
    * las salas solo existiran mientras el dueño 
* una vista para poder chatear dentro de la sala

    * dicha sala debe mostrar las personas conectadas y el historial de los chats actualizados

    * el creador de la sala debe tener un distintivo
    * debe mostrar el historial del chat que se ha realizado en la sala
    * cada mensaje debe indicar quien lo creo y la hora en la que ha sido creada , valor texto
    * las salas deben tener nombre requerido
    * las salas privadas deben tener contraseña
    * debe haber la posibilidad de salirse de una sala
